# GitHub repository description and topics

## Description (limit 350 characters; recount after any edit)

Windows tool: load a video, mark up to 10 start/end segments, reorder them, and get one exact MP4 with only those parts. Always re-encodes (H.264/AAC) for frame-accurate cuts; the original is never changed. VLC preview, FFmpeg engine, English and Russian interface. Python/Tkinter. Built with Claude Code.
